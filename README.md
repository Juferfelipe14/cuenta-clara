# Cuenta Clara

Herramienta web gratuita para trabajadores independientes en Colombia:

- **Cuenta de cobro en PDF**: valor en letras, consecutivo automático, datos bancarios, firma.
- **Calculadora de seguridad social 2026**: salud, pensión, ARL, fondo de solidaridad y caja (incluye el cotizante tipo 76 por semanas).

Todo corre en el navegador; no se envían datos a ningún servidor.

Sitio: https://juferfelipe14.github.io/cuenta-clara/
